# البدء السريع مع Shared MCP Gateway

[English](../../README.md)

## بوابة واحدة لخوادم MCP الخلفية الحالية

يتيح Shared MCP Gateway لـ Copilot تحميل واجهة ثابتة من **6 أدوات للبوابة** في البداية، ثم البحث عند الحاجة عن أدوات الخوادم الخلفية التي أعددتها واستدعائها. وحتى إذا احتوى الكتالوج على نحو **1,000 أداة**، فلا يلزم إرسال جميع تعريفاتها إلى العميل مسبقًا.

تُعاد الاستفادة من كتالوج الخوادم الخلفية واتصالاتها بين جلسات Copilot CLI المتعددة، مما يقلل تكرار تشغيل الخوادم المحلية. لا تثبّت البوابة خوادم MCP ولا توفر بيانات اعتماد؛ واصل إعداد الخوادم والمصادقة بالطريقة المعتادة لديك.

تشمل الأدوات الست 4 أدوات للاكتشاف/التنفيذ وأداتين عامتين لحجز الخادم. يصلح الحجز لأي خادم خلفي يحتاج إلى حالة سير عمل حصرية، ولا يقتصر على أتمتة المتصفح.

## المتطلبات الأساسية

- Node.js 24 أو أحدث، وnpm، وGit
- Copilot CLI مع دعم الإضافات
- إعداد MCP حالي في Copilot والمصادقة التي تتطلبها الخوادم الخلفية
- Agency اختياري، ولا يلزم للاستخدام المعتاد لـ Copilot CLI

## التثبيت

شغّل الأوامر التالية في **الطرفية**، وليس داخل محادثة Copilot:

```text
copilot plugin marketplace add yeelam-gordon/MCPGateway
copilot plugin install shared-mcp-gateway@mcp-gateway
```

بعد ذلك شغّل Copilot ونفّذ داخله:

```text
/mcp-gateway-setup
```

لا يؤدي تثبيت الإضافة وحده إلى ترحيل إعداد MCP. تعرض أداة الإعداد معاينة أولًا؛ وبعد الموافقة تنشئ نسخة احتياطية من الإعداد الحالي، وتحفظ تعريفات الخوادم الخلفية في دليل خاص، وتحوّل إعداد العميل إلى موصل البوابة المشتركة.

احتفظ بمسار النسخة الاحتياطية وأمر الاستعادة الدقيق اللذين تعرضهما الأداة. قد يحتوي الكتالوج والنسخ الاحتياطية على بيانات اعتماد؛ فلا تنشرها ولا تضفها إلى نظام التحكم في الإصدارات.

عند الانتهاء، أغلق Copilot وافتحه من جديد. تبدأ البوابة تلقائيًا عند أول استخدام للموصل، ولا حاجة إلى إبقاء طرفية أخرى قيد التشغيل.

## آلية العمل

1. يسرد `list_servers` الأسماء المستعارة المعدّة دون تشغيل جميع الخوادم الخلفية.
2. يبحث `search_tools` عن ملخصات الأدوات المناسبة في خادم خلفي محدد.
3. يجلب `get_tool_schema` مخطط الإدخال الكامل للأداة المختارة فقط.
4. يتحقق `call_tool` من الوسائط وقائمة السماح قبل استدعاء الأداة.
5. يحمي `claim_server` و`release_server` سير العمل الكامل لخادم يحتاج إلى وصول حصري، ثم يحرران الحجز بعد انتهاء الاستدعاءات النشطة.

للعميل والبوابة وخادم MCP أدوار مختلفة، لكن الاستخدام اليومي لا يتطلب معرفة تفاصيل البروتوكول: أعدّ خوادمك الخلفية كالمعتاد، ودع Copilot يكتشفها ويستدعيها عبر البوابة.

## التحديث والاستعادة

بعد تحديث الإضافة، شغّل `/mcp-gateway-setup` لاعتماد بيئة التشغيل الجديدة بصورة صريحة. انتظر انتهاء الاستدعاءات النشطة، ثم طبّق التحديث وأعد فتح Copilot؛ فتنزيل الإضافة وحده لا يستبدل بوابة قيد التشغيل.

إذا فشل الإعداد، فأغلق Copilot واستخدم مسار النسخة الاحتياطية وأمر الاستعادة الدقيقين الظاهرين في المخرجات. لا تحذف دليل الخوادم الخلفية الخاص في محاولة للاسترداد.
راجع ملف [README](../../README.md) الإنجليزي لمزيد من المعلومات عن مزامنة الإعداد، وتكامل العملاء، والحجوزات، واستكشاف الأخطاء وإصلاحها.
