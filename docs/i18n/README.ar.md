تستخدم جلسات متعددة مجموعة واحدة من الخدمات الخلفية لتجنب تكرار الذاكرة وعمل بدء التشغيل. يحافظ مسار SDK/stdio المختبر على اتصال MCP الحالي عند إضافة إعدادات (الاتصال الحالي من وكيلك إلى البوابة).

[ابدأ](#first-use) · [التوافق (بالإنجليزية)](../CLIENTS.md#compatibility-summary) · [الأدلة والحدود (بالإنجليزية)](../BENCHMARK.md) · [تحديثات Copilot](../CLIENTS.md#copilot-cli-upgrade)

رسم مفاهيمي بعناوين إنجليزية، وليس لقطة تشغيل أو اختبار أداء. [SVG](../../assets/mcp-gateway-benefits.svg)

- **تجنب ذاكرة الخدمات الخلفية المكررة:** بافتراض مشاركة <code dir="ltr">5 × 1.5 GB</code> في مجموعة واحدة، يُتجنب تكرار <code dir="ltr">6 GB</code> **قبل** الاستهلاك الإضافي للبوابة والموصّلات. ليس توفيرًا صافيًا مقاسًا.
- **أعد استخدام عمل بدء التشغيل:** إذا استخدمت الجلسات الخمس جميع خدمات stdio الاثنتي عشرة، يصبح عدد مرات البدء <code dir="ltr">60 → 12</code>. لا يعني بدءًا أسرع بنسبة <code dir="ltr">80%</code>.
- **احتفظ باتصال MCP الحالي:** حافظت تجربة SDK/stdio على الاتصال بعد إضافة إعدادات فقط وإعادة تشغيل البوابة المملوكة بعد انتهاء العمل. لا تثبت hot reload أو استمرار الاستدعاءات النشطة أو جميع واجهات المحادثة الأصلية. قد يتطلب التسجيل الأول وترقية بيئة التشغيل إعادة تشغيل العميل. [SDK/stdio](../BENCHMARK.md#configuration-only-connection-continuity)

<a id="resource-examples"></a>
**متى تستخدمها أو تتجاوزها:** للجلسات المتعددة التي تشترك في الموصّل والكتالوج نفسيهما. قد يكون MCP المباشر أبسط لجلسة واحدة أو خدمات خفيفة. في الاختبار الخفيف زاد مجموع working set للعمليات من <code dir="ltr">357.0 → 564.0 MiB</code>؛ استغرق أول طلب مشترك، من تشغيل بوابة جديدة إلى أول نتيجة مفيدة، <code dir="ltr">1886.7 ms</code> مقابل <code dir="ltr">503.5 ms</code> مباشرة. الفائدة الصافية تعتمد على الاستهلاك الإضافي. [BENCHMARK](../BENCHMARK.md#sharing-model-and-evidence)

<a id="first-use"></a>
## أول نتيجة مفيدة: قراءة مأذون بها عبر البوابة

يلزم Node.js 24+ وnpm وGit وCopilot CLI مع الإضافات، وتكاملات MCP مهيأة مع المصادقة المطلوبة. يمر التثبيت الأول عبر Copilot CLI؛ Windows منصة الاختبار الرئيسية. يختلف مستوى التحقق بين العملاء. [Copilot `/help` · `/plugin`](../CLIENTS.md#copilot-plugin-eligibility).

**قبل التثبيت:** قد تحتوي الإعدادات والكتالوج الخاص والنسخ الاحتياطية على بيانات اعتماد؛ لا تنشرها. قد تتصل الخدمات الخلفية بخدمات بعيدة. تُثبّت بيئة تشغيل مستمرة؛ استعادة الإعدادات أو إزالة الإضافة لا توقف البوابة. [REFERENCE](../REFERENCE.md#planned-exit) الحالة الخاصة المحلية ورموز البوابة المحفوظة متاحة للمالك فقط، وليست مشفرة تشفيرًا إضافيًا.

```powershell
copilot plugin marketplace add yeelam-gordon/MCPGateway
copilot plugin install shared-mcp-gateway@mcp-gateway
```

1. افتح Copilot CLI واستدعِ `/mcp-gateway-setup`. راجع المعاينة ووافق فقط على التغييرات المقصودة. احتفظ بالنسخ الخاصة وأوامر التراجع. تثبيت الإضافة وحده لا يدمج الإعدادات.
2. أغلق Copilot ثم أعد فتحه، ونفّذ `readinessCommand` الدقيق الذي أعاده الإعداد بحسب تعليمات كائن الأمر. أمر الفحص وحده لا يبدأ بوابة غير مشغلة. [readinessCommand](../REFERENCE.md#readiness-command-object) احفظ كائن JSON المُعاد فقط؛ `.command` هو الملف التنفيذي الموافق عليه و`.args` هي وسائطه الدقيقة بالترتيب نفسه.
3. اختر قراءة غير ضارة ومأذونًا بها في تكامل قائم. غيّر المهمة بين القوسين فقط؛ استخرج الأسماء والأدوات والوسائط من الاكتشاف والمخطط، ولا تخمّنها.

> استخدم البوابة في [مهمة القراءة المأذون بها]. نفّذ `list_servers` ثم بحثًا محددًا بـ `search_tools` و`get_tool_schema`؛ جهّز وسائط مطابقة للمخطط بقيم اختبار مأذون بها وغير حساسة. احصل على الموافقات المعتادة. إذا كان `requiresExclusiveAccess: true` فاستخدم `claim_server` مرة واحدة قبل `call_tool` و`release_server` بعد انتهاء جميع الاستدعاءات؛ الخدمات غير الحصرية لا تحتاج حجزًا. أظهر السجل الفعلي أو نتيجة فارغة موضحة وافحص الأخطاء، لا مجرد رد البوابة. إذا كانت النتيجة مجهولة فلا تكرر المحاولة: أبقِ الحظر وسلّم الحالة بصورة خاصة إلى مسؤول التثبيت.

4. في جلسة ثانية تستخدم الموصّل والكتالوج نفسيهما ابحث عن الاسم نفسه: يُتوقع `ready` والقدرات نفسها. هذا يتحقق من الاكتشاف المشترك، لا هوية العملية أو توفير RAM. [MCP](../REFERENCE.md#first-shared-workflow) [مثال echo علني ونتيجته](../REFERENCE.md#public-echo-illustration).

**عند الفشل:** إن كان الكتالوج فارغًا فراجع الإعداد والمعاينة؛ ابحث بكلمات من وصف الخدمة. اتبع المرجع لأخطاء المصادقة أو الجاهزية، دون عملية موازية لتجاوز البوابة. تحرير الحجز أو قطع الاتصال لا يلغي نتيجة حصرية مجهولة ولا يرفع الحظر بأمان. طابق النتيجة ونسّق إعادة تشغيل البوابة المملوكة ثم احجز من جديد. [Authentication](../REFERENCE.md#native-http-oauth) · [Recovery](../REFERENCE.md#setup-recovery) · [Unknown outcome](../REFERENCE.md#unknown-exclusive-result)

**التوقف عن الاستخدام:** أنه العمل والاستدعاءات، واستعد أو أزل موصّلات العملاء المعنيين، ثم اتبع التسليم للمشغّل للتحقق من توقف البوابة المملوكة. استعادة الإعدادات ليست إيقاف العملية. احتفظ بالحالة الخاصة وبيانات الاعتماد والسجل والعمليات غير ذات الصلة. [Exit](../REFERENCE.md#planned-exit)
