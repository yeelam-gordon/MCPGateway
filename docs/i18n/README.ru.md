# Shared MCP Gateway

[English](../../README.md)

> Это локализованный обзор. Английский [README](../../README.md) и англоязычное руководство по клиентам по ссылкам ниже являются основными источниками полных инструкций по установке, обновлению и технических подробностей.

## Экономьте RAM. Оставляйте контекст для работы. Инструменты — по запросу.

**Больше агентов должно означать больше выполненной работы, а не больше копий одной конфигурации MCP.**

### 5 агентов. 12 подключений MCP. Одна общая конфигурация.

*Пример: **12** подключений предоставляют **1,000** инструментов, а каждая независимая конфигурация использует **1.5 GB** RAM локальных процессов.*

| Преимущество | Отдельная конфигурация для каждого агента | С MCPGateway |
|---|---|---|
| **Экономия RAM** | **7.5 GB** для пяти независимых конфигураций MCP. | **1.5 GB совместно**, плюс накладные расходы шлюза и коннекторов. **Исключается 6 GB дублируемой памяти.** |
| **Контекст для работы. Инструменты по запросу.** | Каждый агент заранее загружает **1,000 определений инструментов**; при добавлении подключений MCP число может расти. | Заранее только **6 инструментов шлюза — на 99.4% меньше определений**. Все **1,000** инструментов остаются доступны; агент находит и загружает только нужные. Новые подключения не требуют загружать их полные каталоги во все агенты. |

**Сохраняйте агентов и подключения MCP. Не заставляйте каждый сеанс нести собственную копию.**

*Значения RAM приведены для примера и не являются измеренной экономией; память самих агентов учитывается отдельно. Число определений не равно экономии токенов, а клиенты с отложенной загрузкой могут получить меньшую выгоду для контекста. Совместное использование не расширяет окно контекста и не делает общий расход RAM постоянным.*

## Как это работает

Шлюз всегда показывает агенту 6 инструментов: 4 для поиска и вызова возможностей и 2 для интеграций, которым нужен эксклюзивный рабочий процесс. Новые подключения не увеличивают начальный интерфейс; полная схема загружается только для выбранного инструмента. Используются уже настроенные и аутентифицированные подключения, без установки сервисов и выдачи учетных данных.

Один общий каталог MCP может обслуживать несколько агентов: начните с **10** подключений в Copilot, затем явно перенесите поддерживаемую конфигурацию Claude с **2** новыми подключениями, чтобы оба агента использовали одни и те же **12**; одна лишь установка плагина не объединяет их автоматически. Одноименные записи дедуплицируются только при полностью одинаковых определениях псевдонимов, а не просто потому, что указывают на один сервис; при конфликте процесс останавливается для проверки. Перенос сначала показывает предварительный просмотр, создает резервную копию и отклоняет неподдерживаемые нативные настройки; это также не означает, что все нативные клиенты прошли сквозное тестирование, см. [руководство по переносу (на английском)](../CLIENTS.md#cross-client-migration).

**Требования:** Node.js 24 или новее, npm, Git и Copilot CLI с поддержкой плагинов для текущей первоначальной настройки. Agency необязателен.

Конфигурация и копии могут содержать учетные данные; не публикуйте их и не добавляйте в систему контроля версий.
